AI-Supervised Autonomous Control Architecture for PX4 Drones
  • System architecture: designed a formal three-layer separation of responsibilities — AI as strategic advisor, a tactical middleware layer, and PX4 as the real-time flight executor — bridged via ROS 2 and uXRCE-DDS.
  • Ground-link-loss decision framework: authored phase-dependent autonomy rules (preflight, transit, active task, target-detected, return-to-base) and a graduated reconnection timeout ladder, so the vehicle degrades gracefully instead of on a single connect/disconnect threshold.
  • Work Index energy-margin model: specified a continuous flight-minutes accounting model (task completion vs. return-to-base vs. safe landing vs. post-landing beacon reserve) that governs when the vehicle must abort, return, or land immediately — with locatability preserved as the top priority.
  • Safety-first scoping: target/candidate detections trigger loiter-and-hold rather than autonomous action, even at medium confidence, since the cost of a false positive outweighs the cost of an unnecessary loiter.

Flagship Research

Interstate Corn Price Concurrency Iowa vs. Ohio, 2015–2026
Independent Research
github.com/premananda-cloud/price_latency
A reproducible econometric study of short-run synchronization and long-run equilibrium between two major U.S. corn markets, built on 137 months of USDA NASS data.
  • Data pivot, documented: moved from an annual-only commodity source to the NASS monthly series after empirically testing which commodities and geographies actually supported the question.
  • Full methodology chain: ADF stationarity testing → time-lagged cross-correlation on returns → Granger causality → Engle-Granger cointegration on levels → Zivot-Andrews structural break test.
  • Headline result: same-month price synchronization between Iowa and Ohio (k*=0, ρ=0.84), stable across a train/holdout backtest, with Iowa leading Ohio in Granger causality.
  • Reported a genuinely mixed long-run finding: a rolling 60-month cointegration test shows the relationship holds in only 26% of windows — strong short-run co-movement without robust long-run equilibrium.
  • Caught and flagged an unverified causal narrative from an earlier draft before it entered the paper.

MedLedger + CypherAegis Healthcare Security
Hack4Humanity 2026 · Team Praxis
MedLedger · CypherAegis
  • Zero-knowledge sharing model: a patient-controlled medical record vault where the server stores only ciphertext it is mathematically unable to decrypt — no plaintext record, private key, or data-encryption key ever reaches the backend.
  • Two-layer security: a conventional email/password/TOTP account gate, separate from an Ed25519/X25519 vault keypair generated client-side and never transmitted — so a full server compromise still yields no decryptable data.
  • CypherAegis: built the underlying cryptographic primitives (ECDSA, Shamir secret sharing) as a reusable library shared across projects rather than duplicated per-app.
  • Backend: async FastAPI + PostgreSQL (SQLAlchemy 2.0 / asyncpg), Argon2id password hashing, JWT auth, TOTP 2FA, Flyway-managed migrations, Docker Compose deployment; API live on Render with a 112-file test suite across auth, database, middleware, and services.
